# 🌍 COVID-19 Data Visualization using Folium

This project visualizes global COVID-19 confirmed cases using the Python library **Folium**. The interactive map displays red bubble markers on countries, indicating the number of confirmed cases.

## 📌 Features

- Interactive world map using **Folium**
- Circle markers sized and styled to represent confirmed cases
- Popup tooltips displaying:
  - Country name
  - Number of confirmed cases
- Zoom and pan support for exploring data globally

## 📂 Dataset

The dataset includes:
- **country_wise_latest**
- **world_coordinates**
  



## 🧪 Technologies Used

- Python 🐍
- Pandas 📊
- Folium 🌐
